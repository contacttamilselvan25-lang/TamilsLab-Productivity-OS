# Tamils-lab-productivity
🌟 TAMIL'SLAB (PRODUCTIVITY) — App Overview
TAMIL'SLAB (PRODUCTIVITY) is a private, all-in-one executive workspace app designed for focus, clarity, and calm productivity. It combines task management, interactive schematics, calendar time-blocking, rich notes, local file organization, habit tracking, and server-side Gemini 3.6 Flash AI assistance.

🛠️ Key Features & Modules
1. ☀️ Today View (Daily Command Center)
Daily Focus Banner: Displays your top priority goal for the day.
Time-Blocked Agenda: Visual schedule showing your meetings, focus blocks, and breaks.
AI Daily Planner ("Plan My Day"): One-click AI tool that analyzes your tasks, calendar commitments, and goals to automatically generate a realistic daily schedule.
2. ☑️ Tasks Module
Priority System: Organize tasks by P1 (Urgent), P2 (High), P3 (Medium), and P4 (Low).
Subtasks & Categorization: Group tasks by project (Work, Personal, Health, Project, Ideas).
Kanban & List Views: Switch between traditional list mode and visual status columns.
3. 📁 Files & Organizer (100% Local File Storage)
Persistent Local File Storage: Upload PDFs, spreadsheets (.xlsx, .csv), images, code, and text files.
Offline Access: All files are converted to local Data URLs so you can preview, view, and download them to your computer anytime.
AI Document Inspector: Ask AI questions about any uploaded document to summarize key deadlines, action items, or data.
4. 📐 Drawing & Schematics Studio
Schematic Flowchart Builder: Create process flows, decision trees, cloud architectures, and database diagrams with smooth bezier connector arrows.
Freehand Sketch Canvas: Draw ideas using Pen, Marker, Highlighter, Eraser, Line, Arrow, Rectangle, and Circle tools.
Styled Notes: Typography customizer with custom fonts, sizes, and post-it card themes.
5. 📝 Notes Module
Distraction-Free Markdown: Write, organize, and filter notes by folder and tags.
AI Note Summarizer: Automatically extract actionable tasks from meeting notes and save them into your task list.
6. 📅 Calendar & Time-Blocking
Color-coded event tracking (Work, Focus, Personal, Meeting).
Seamless synchronization with your daily planner and AI workspace context.
7. ⚡ Habit Tracker
Build daily and weekly habits (Mindfulness, Fitness, Learning, Health).
Visual streak progress bars and completion history.
8. 🎯 Goals Module
Track Quarterly, Yearly, and Monthly goals with progress percentage bars.
AI Goal Breakdown: AI automatically breaks down large goals into 3 to 5 realistic sequential milestones.
9. ⏱️ Focus Timer (Pomodoro)
Customizable focus timer intervals (Pomodoro, Short Break, Long Break).
Ambient sound generators (Rain, Coffee Shop, White Noise) using Web Audio API.
10. 🤖 Integrated AI Assistant
Conversational assistant powered by Gemini 3.6 Flash.
Has full context awareness of your active tasks, calendar, notes, goals, and workspace facts to help answer questions and organize your day.
🔒 Privacy & Local Desktop Setup
100% Offline Capability: Your workspace data, notes, drawing sketches, habits, and files remain saved locally in your browser storage.
Desktop Application Shortcut: Runs as a dedicated Standalone Desktop App Window (Option B) without browser tab clutter, complete with custom lightbulb icon (app_logo.ico).
Data Export & Backup: Export your entire workspace into a .json backup file anytime.
